# Generative AI in Python Masterclass 🚀

An 8-week intensive bootcamp transitioning from AI fundamentals to deploying production-ready, autonomous AI agents. 

## 🎯 Objective
To build a comprehensive portfolio of Generative AI applications using Python, LangChain, LangGraph, and Docker, focusing on secure, scalable, and context-aware LLM architectures.

## 🛠️ Tech Stack
* **Language:** Python
* **Frameworks:** LangChain, LangGraph
* **Models:** Google Gemini, OpenAI, Llama-3 (Local)
* **Databases:** Qdrant (Vector), Neo4j (Graph), SQLite (Memory)
* **Infrastructure:** Docker, AWS ECS, LangSmith (Tracing)
